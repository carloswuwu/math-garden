# 數學樂園 · Math Garden

> 🌐 **線上版（任何裝置都能開）**：<https://carloswuwu.github.io/math-garden/>

一個**完全離線**、可安裝到桌面 / 主屏幕的兒童數學學習應用。陪伴孩子從**學前**一路學到**大學**：每個知識點都有小課堂講解、自適應練習和計分測驗，界面中英雙語一鍵切換，進度保存在本機。

> 為 5 歲左右、已經會簡單加、減、乘法的孩子設計；題目全部由程序隨機生成，永遠不重樣。

## 怎麼開始

任選一種方式：

1. **雙擊 `play-math.bat`**（Windows）：優先打開建置後的 `dist/index.html`（沒有 dist 時退回開發用 `index.html`），在乾淨的桌面應用窗口裡打開，無需聯網。
2. **雙擊 `dist/index.html` 或 `index.html`**：用任意瀏覽器直接打開（建置版是單一 bundle，載入更快）。
3. **安裝成 App（PWA）**：部署到 HTTPS（如 GitHub Pages）後，在 Chrome/Edge 裡點「安裝」，即可離線全屏使用；手機 / 平板也能添加到主屏幕。有新版本時會顯示「新版本」按鈕，確認後才重新載入。

> 進度保存在瀏覽器本地（`localStorage`）；家長中心支持**導出 / 導入**進度，方便備份或換設備。

## 功能特點

- 🧑‍🏫 **小課堂**：每個技能有講解、舉例、小技巧和圖示（圓點、數軸式圖示、乘法點陣、分數圓餅、三角形／圓形／長方體／座標圖）。
- 📐 **幾何圖示**：三角形、圓形、長方體、座標平面等以 SVG 圖示顯示，配合面積、周長、體積公式。
- 📖 **一步步示範**：小課堂可點「看一步步示範」，逐步示範如何解一道題，按「換一題」可再看更多例子。
- 🧩 **每階段都有應用題**：每個學習階段都包含應用題（Word Problems），練習讀題與選用正確運算。
- 📚 **課程大綱**：內置香港教育局數學課程大綱（小一至中六的學習範疇與學習單位）作參考，方便家長規劃。
- 📐 **公式一覽**：按課題整理常用公式（面積、體積、指數、數列、二次方程、三角、概率統計等），以 KaTeX 排版作參考。
- 🏆 **挑戰區**：首頁金色入口，6 個主題、**20 種**奧林匹克風格加難題、每主題 3 級難度——2 的次方取餘數／個位數字、同餘、HCF/LCM、方格路徑與長方形計數、握手、字母排列、容斥、時針夾角、梯形／多邊形內角、數列規律、鴿巢原理、工程合作、混合濃度、火車相遇／追及、骰子概率、硬幣二項概率等；**全部改為輸入答案，不再提供選項**（可輸入整數、小數或分數），每題都有完整解題步驟。
- ⚖️ **練習計分公平**：練習只有「第一次就答對」才計入掌握度／連對／難度，重試答對會有回饋但不計分；每個技能的測驗及格線可用 `mastery.quizPass` 設定（預設 80%，2 星＝通過）。
- 📚 **深入淺出的教學**：全部 **108 課**都有概念、例子、小貼士，並加入**解題步驟**與**常見錯誤**，每課都是完整策略而不是一筆帶過。
- 🧮 **正式數學排版**：所有公式、方程、指數都用 **KaTeX** 排版（不再顯示 `^` 或 `d/dx(ax^n)` 這類純文字）；分數、根號、上下標與方程都像教科書一樣整齊。
- ⌨️ **輸入答案防猜**：挑戰區所有題目、以及中學起的測驗／考試每 3 題有 1 題改為鍵入答案（分數如 `1/36`、小數如 `2.5` 都接受）；小學與練習仍用選擇題，避免年幼學生因輸入格式失分。
- 📝 **綜合考試**：每個年級都有 20 題模擬試卷，混合該年級多個技能出題，題目不重複、同一模板不會連續出現，難度以高階題為主。
- 🎯 **分難度應用題**：應用題由淺入深，除了加減乘、面積、百分數、比例、速率、盈利、複利息，還有 10 種多步／跨概念題型（單價、找續、逆算折扣、批量盈利、比例差、速率放大、鋪地磚、補測驗平均分、價目表找續、逆推方程），情境與問法多樣，不再只是換數字。
- ✍️ **自適應練習**：按正確率智能出題，連續答對自動加難度、連續答錯自動降難度。
- 🏆 **計分測驗**：每章 10 題，完成後出成績單和星星。
- ⭐ **掌握度與解鎖**：答對達標即掌握，逐個解鎖下一知識點。
- 👨‍👩‍👦 **家長中心**：查看總星星、連續天數、各技能掌握度，導出 / 導入 / 重置進度。
- 🌗 淺色 / 深色自動切換，手機、平板、電腦都適配。
- ♿ 無障礙：每畫面單一 h1、鍵盤與讀屏名稱、對話框焦點陷阱、題目圖示文字替代，並以 axe-core 子集自動檢查。
- 🔤 中英雙語一鍵切換（界面與全部課程內容）。
- 📴 無第三方依賴、無網絡請求（在線版僅首次加載需要網絡）。

## 開發與測試

> 交接文件與完整路線圖：**[docs/PLAN.md](docs/PLAN.md)**（目前狀態、架構、待辦與新對話的啟動提示）。

### 建置（esbuild）

```bash
npm ci               # 安裝建置依賴（esbuild）
npm run build        # 輸出 dist/app.<hash>.js、dist/index.html、dist/sw.js
```

- 建置是**決定性**的（文字檔先統一 LF、esbuild 版本納入 hash）：同一份 repo 在任何平台都產生相同的 `dist/`，CI 會用 `git status --porcelain -- dist` 檢查是否忘記提交建置結果。
- 改完 `math-core.js` / `app.js` / `style.css` 等源碼後，記得 `npm run build` 並把 `dist/` 一併提交。
- Service Worker 的 precache 清單與 cache 版本由建置產出，不再手動維護。

### 測試

純邏輯／內容契約測試（不需要 jsdom；`contract`／`ui` 的 dist 檢查需要先建置）：

```bash
node tests/core.test.js         # 答案 oracle（MATH_SPEC）、判分、掌握度、進度清洗
node tests/generators.test.js   # 生成器性質、題庫池大小、解題步驟不變量
node tests/contract.test.js     # MATH_SPEC 自檢、素材清單、i18n、解題覆蓋、公式／技能對齊、dist 一致性
```

界面與無障礙測試（需先安裝測試依賴，會一併安裝 axe-core）：

```bash
npm install --prefix tests        # 或 pnpm install --dir tests --config.node-linker=hoisted
node tests/ui.test.js
node tests/a11y.test.js
```

- `tests/core.test.js`：對所有題型做大量抽樣，用 `MathCore.answerFromMath`（唯一的 MATH_SPEC）交叉驗證答案、選項唯一性、掌握度、自適應與 `sanitizeProgress` 模糊測試。
- `tests/ui.test.js`：用 jsdom 加載整個應用，驗證首頁渲染、語言切換、路由／Back-Forward、練習與測驗、session 恢復、進度持久化與匯入、更新 chip；另外對 `dist/` 打包版做一次冒煙測試（沒有 dist 時自動跳過）。
- `tests/a11y.test.js`：無障礙契約——每個畫面恰好一個 h1、aria-labelledby、無重複 id、所有按鈕／開關有名稱、導航聚焦標題、live region 宣告、對話框背景 inert／aria-hidden、語言切換同步 ARIA、題目附圖的文字替代，以及 axe-core（jsdom 支援的規則）0 violations。
- `tests/generators.test.js`：生成器性質（選項、分數、概率、題幹）、題庫池下限、難度階梯與解題步驟。
- `tests/contract.test.js`：跨層契約——`MATH_SPEC` 自檢、HTML/manifest/SW 素材存在且相對、`t()` 字面量與技能／課堂中英齊全、每個題型都有解題步驟並以答案收尾、公式與技能標記對齊、`dist/` 與生成的 SW 自我一致（hash、precache 清單、更新流程、gzip 體積）。
- `tests/make_icon.py`：重新生成應用圖標（需要 Pillow）。

### 部署

`.github/workflows/pages.yml` 會建置並發佈 `dist/` 到 GitHub Pages。**需要一次性的 repo 設定**：Settings → Pages → Build and deployment → Source 選「GitHub Actions」。在切換之前，偵測步驟會發出 warning 並跳過部署，現有的「Deploy from a branch」仍然服務 repo 根目錄（舊入口，仍可正常使用）。

## 說明

- 應用名「數學樂園 · Math Garden」為暫定名，可隨時在 `i18n.js`、`manifest.webmanifest` 和 `index.html` 的 `<title>` 中修改。
- 語音朗讀暫未內置（v1 為文字講解）；如需語音，可後續接入瀏覽器 TTS。
